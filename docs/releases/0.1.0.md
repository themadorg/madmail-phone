Madmail Mobile 0.1.0 is the last alpha of the 0.1 line. It runs on ARM64 phones with Android 8 or later and bundles the Madmail engine v2.30.5. GitHub Actions built and signed this APK from the tagged source with the existing release key, so it updates 0.1.0-alpha.4 in place.

## What's new since alpha.4

- **Statistics tab.** The bottom bar now has four tabs: Home, Stats, Invite and Settings. Live counters, storage and federation numbers moved from Home to Stats. When there is nothing to read, Stats says why.
- **New Home header.** The server's icon and name sit in the middle of the screen. Under them, a status dot shows the power state (green and pulsing when live) next to where the server runs, such as "Wi-Fi · 192.168.1.20".
- **Clear mobile-data handling.** On mobile data alone, guests can't reach the phone. Home and Invite now say so plainly and offer Wi-Fi and hotspot shortcuts, and the status dot turns orange. The guest address fills itself in again when a network returns. During setup, the "Share a network" step checks the connection live.
- **Long-press a server.** In the server list, a long press lifts the row and shows quick actions: open Statistics, Invite or Settings, change its name and icon, copy its address, or remove it. Removing asks first.
- **Onboarding titles decode like a terminal.** Each intro title resolves out of falling glyphs, above a typed line with the real command, ports or link behind it. With "Remove animations" turned on, the text just appears.
- **Debug menu: Replay onboarding.** Testers can walk through the intro again without clearing data. Long-press Home to open the menu.

## Also in the 0.1 line

- Guided first-run setup for this phone or a remote server over SSH or the Admin API, including provider guides.
- One switch turns hosting on and off, with a confirmation and live states. The status shows in the bottom bar.
- Account QRs and invitation links, with labels, use limits, expiry and revocation.
- Server settings in grouped pages, plus app lock, haptics, toasts and a debug menu for testers.

## Install

Download `madmail-mobile-0.1.0-arm64.apk`, or `-arm64-full.zip` for the APK with its source, and install it.

Release signing certificate SHA-256:
`3a03365df303f177286f3abdcda98f9907a4648e94b54e7a88027ed52912b81f`

> **Warning:** this APK cannot update a debug-signed or development build. Don't uninstall a phone that holds mail data just to install it: uninstalling deletes its private server data.

## Verify

`SHA256SUMS` covers the APK, the source archive and the provenance files. `source-revisions.txt` pins the exact mobile, engine and admin-web revisions this build came from.

## Known limits

- Hosting keeps the address it started with. If the phone switches networks while hosting, turn hosting off and on again.
- Each unused account QR leaves an entry on the server's blocklist, and nothing prunes it yet.
- Root ports, guided backup restore and full web-admin parity are not available yet.
