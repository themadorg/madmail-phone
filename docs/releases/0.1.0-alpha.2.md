# Madmail Mobile 0.1.0-alpha.2

This alpha adds guided onboarding and makes phone hosting and guest connections easier to understand.

- Welcome, explicit phone/remote host selection, phone naming, optional background access, and a setup review. Existing configured servers remain accessible without repeating onboarding.
- Animated navigation and engine-driven starting, running, stopping and failure states.
- Quick generation of a personal account QR and invitation controls visible on phone Overview, with enlargement and sharing.
- Android Back navigation, server switching and keyboard-aware setup controls.

Android version code: 3. Android 8 or later, ARM64. Bundled Madmail engine: 2.30.5.

The UX was exercised on a Pixel 6a running Android 17 using development builds, including a separate fresh-install test. Local unit tests and debug lint passed before release preparation. Release validation additionally checks packaging, engine hashes, ABI/alignment and the existing release signing identity. This is an alpha; a new cross-device connection test and clean-device testing of the production-signed package are not claimed.

The APK uses the existing Madmail release key. It can update the previous release-signed alpha. The development-signed app installed on the test phone uses a different signer: do not uninstall it to force an update, since that deletes private server data.

The source archive includes the app, pinned engine and admin sources, and the Android engine patch. Checksums and build provenance accompany the binaries. Root ports, guided backup restoration and complete web-admin parity remain unavailable.
