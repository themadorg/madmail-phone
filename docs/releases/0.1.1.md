Madmail Mobile 0.1.1 is a patch release of the 0.1 line. It runs on ARM64 phones with Android 8 or later and bundles the Madmail engine v2.30.5. GitHub Actions built and signed this APK from the tagged source with the existing release key, so it updates 0.1.0 in place.

## What's new since 0.1.0

- **Mobile data counts as a network.** The server always listened on every address on the phone, but the app only offered Wi-Fi, hotspot, Ethernet and VPN addresses. Some carriers let subscribers in the same country reach each other, so mobile data addresses now appear in the guest address list as "Mobile data". When the app picks an address itself, it still prefers Wi-Fi, a hotspot or Ethernet, then a VPN, then mobile data. You can choose a mobile address yourself at any time.
- **"No network" only when there is none.** Home, Invite and setup no longer warn about mobile data. The orange notice now appears only when the phone has no usable address at all.
- **Quotas read the way you enter them.** Storage quotas are entered in 1024-based megabytes, but were shown in 1000-based units, so a 1024 MB quota read "1.07 GB". Quotas and account storage now use 1024-based units throughout: 1024 MB reads "1 GB".

## Install

Download `madmail-mobile-0.1.1-arm64.apk`, or `-arm64-full.zip` for the APK with its source, and install it.

> **Warning:** this APK cannot update a debug-signed or development build. Don't uninstall a phone that holds mail data just to install it: uninstalling deletes its private server data.

## Verify

`SHA256SUMS` covers the APK, the source archive and the provenance files. `source-revisions.txt` pins the exact mobile, engine and admin-web revisions this build came from.

## Known limits

- Whether guests can reach a mobile data address depends on the carrier. Many carriers put phones behind shared addresses that others can't reach.
- New accounts use one of the phone's IPs as their mail domain. Mail sent to a different IP of the same phone is accepted only if the phone used that IP as its address before.
- Hosting keeps the address it started with. If the phone switches networks while hosting, turn hosting off and on again.
- Each unused account QR leaves an entry on the server's blocklist, and nothing prunes it yet.
- Root ports, guided backup restore and full web-admin parity are not available yet.
