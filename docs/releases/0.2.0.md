Madmail Mobile 0.2.0 adds the app's first translations. It runs on ARM64 phones with Android 8 or later and bundles the Madmail engine v2.30.5. GitHub Actions built and signed this APK from the tagged source with the existing release key, so it updates 0.1.x in place.

## What's new since 0.1.1

- **Five new languages.** The app is now available in Portuguese, Russian, Spanish, Farsi and French, alongside English. It follows the phone's language. On Android 13 or later, you can also pick a language for Madmail alone in the system settings, under Apps → Madmail → Language.
- **Right-to-left layout for Farsi.** Screens mirror when the app runs in Farsi.
- **Build toolchain update.** The app now builds with Android Gradle Plugin 9.5, Gradle 9.8 and Kotlin 2.4. This changes nothing you can see in the app.

## Install

Download `madmail-mobile-0.2.0-arm64.apk`, or `-arm64-full.zip` for the APK with its source, and install it.

Release signing certificate SHA-256:
`3a03365df303f177286f3abdcda98f9907a4648e94b54e7a88027ed52912b81f`

> **Warning:** this APK cannot update a debug-signed or development build. Don't uninstall a phone that holds mail data just to install it: uninstalling deletes its private server data.

## Verify

`SHA256SUMS` covers the APK, the source archive and the provenance files. `source-revisions.txt` pins the exact mobile, engine and admin-web revisions this build came from.

## Known limits

- Some text is still English in every language: server status and error messages from the engine, server setting names and hints, the hosting notification, network names such as "Wi-Fi" and "Hotspot", and the debug menu.
- The translations have not been reviewed by native speakers yet. Corrections are welcome.
- Whether guests can reach a mobile data address depends on the carrier. Many carriers put phones behind shared addresses that others can't reach.
- Hosting keeps the address it started with. If the phone switches networks while hosting, turn hosting off and on again.
- Each unused account QR leaves an entry on the server's blocklist, and nothing prunes it yet.
- Root ports, guided backup restore and full web-admin parity are not available yet.
