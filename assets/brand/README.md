# Madmail identity

The white envelope folds into an abstract M on violet `#6534D5`. The symbol uses a broad silhouette that remains readable at launcher size.

- `../icon.svg`: scalable production artwork, with rounded-square backing for web/docs.
- `logo.png`: generated raster concept/export, preserved at its original resolution.
- Android: `ic_launcher_foreground.xml` is the code-native vector adaptation. Adaptive masking provides the launcher silhouette. Android 13+ also receives a monochrome foreground for themed icons.

The generated image was created for this project with the built-in image tool. Prompt direction: a bold white geometric envelope/M, central safe margins, rich violet field, no text, shadows or mockups. The SVG/Android paths are an authored adaptation for crisp scaling, not a pixel-identical trace of the raster.

Keep the mark centered, preserve the envelope's negative space, and do not add lettering inside the launcher icon.
