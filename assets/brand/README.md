# Madmail identity

The mark is the official Madmail logo from [madmail.chat](https://madmail.chat/): an iridescent face with a censored `&$!#%` bar.

- `madmail_logo.png`: 320×320 RGBA copy of the site logo. Android uses the same file at `app/src/main/res/drawable-nodpi/madmail_logo.png`.
- Android: `ic_launcher_foreground.xml` insets the logo into the adaptive-icon safe zone over near-black `#111111`. The logo is a full-color raster, so there is no monochrome themed-icon layer.
- `../icon.svg` and `logo.png`: earlier violet envelope concept, kept for reference only.

Keep the mark centered and do not add lettering inside the launcher icon.
